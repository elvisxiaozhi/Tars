# Step 2.22 — Trailing 中间档：保本 → 锁 +5¢

## 概要

把 trailing stop 中间档（MFE ≥ +10¢ 但未到 +15¢）的止损线从 `entry`（保本）
升到 `entry + $0.05`（锁 5¢ 浮盈），堵死「冲到 +11¢~+12¢ 然后回吐到 entry-2¢
亏出场」的死区。

## 数据依据（4-29 ~ 4-30，19 candles）

|---|---|---|---|---|---|---|---|---|
| 4-29 4PM | DOWN | 0.29 | 0.41 | +12¢ | 0.27 | -$0.34 | 0.34 | +$0.50 |
| 4-30 1AM | DOWN | 0.29 | 0.41 | +12¢ | 0.27 | -$0.34 | 0.34 | +$0.50 |

| **合计** | | | | | | **-$1.40** | | **+$1.50** |

**净提升 +$2.90**（占当日 +$5.77 的 50%）。

## 设计决策

### 1. 为什么是 +5¢ 而不是更激进 / 更保守

| 候选 | 评 |
|---|---|
| entry（保本，旧） | 三笔全部触发，回吐到 entry-2¢ 后亏出场 |
| **entry + 5¢**（新） | 锁住 +5¢×10shares ≈ +$0.50 净，覆盖手续费有余 |
| entry + 8¢ | 过紧，可能切掉「+12¢ 回踩 +8¢ 再冲 TP0」的 trip |

+5¢ 的物理含义：在 mfe ≥ +10¢ 时，已经把利润锁到「至少够付费 + 微利」水平。

### 2. 与峰值档（+15¢ 阈值，peak-based）的边界协调

```
      mfe (绝对涨幅)
   0¢ ────── 10¢ ────── 15¢ ──────────────►
   │  -50%   │  锁 +5¢   │  peak-15¢ trailing │
   │  止损    │ （新）    │  保底 entry+10¢     │
```

新规则下 +10¢ 档锁的利润（+5¢）比 +15¢ 档保底利润（+10¢）少 5¢，
逻辑上单调递增、不冲突。

### 3. 风险：会不会切掉「先 +12¢ 回踩 +5¢ 再冲 TP0」的 trip？

今天 19 笔数据中**没有**这种 trip 出现：
- 5 笔 WIN_TP 全部 `mfe5 ≥ 0.45`（即 5min 内已突破 +15¢，直接进入 peak-based 档）
- 没有 trip 在 +12¢ 回踩后再冲到 TP0

需要继续观察一周，若出现 ≥ 1 笔被新规则切早的赢家，再考虑改回 entry+3¢ 或加入 BTC 方向校验。
