# Polymarket BTC 1小时 UP/DOWN 交易策略（优化版）

## 一、入场条件（必须全部满足）

1. **时间窗口**：剩余时间 > 30分钟（最佳入场区间是开盘后5-25分钟）
2. **价格条件**：动态阈值，根据剩余时间调整
   - 剩余30分钟以上：价格 < 30¢
   - 剩余30分钟以下：不入场

## 二、下单方式（关键优化点）

优先使用限价单（Maker），避免市价单（Taker）

- **入场**：在当前价下方0.5-1¢挂限价买单（例：现价25¢，挂24.5¢或24¢），只买5shares
- **出场**：除非系统限制不允许现价单，share过少可能会被限制，否则有止盈档位全部用限价单挂出
- **好处**：不支付taker手续费，还能获得maker返利，回本门槛从2.4%降到接近0
- **例外**：止损触发时，可以使用市价单快速离场

## 三、仓位管理

- **账户总资金**：10 USDC
- **固定下单量**：每次买入 5 shares
- **单仓制**：同一时间最多持有1个仓位，未全部卖出前不允许再次下单，如果已经被强制止损，那么本场不允许再交易

## 四、止盈规则（分档减仓）

以入场价为基准计算，假设入场价为P₀：

| 档位 | 触发价格 | 卖出比例 | 说明 |
|------|----------|----------|------|
| 第一档 | 算上买卖手续费已经回本 | 卖出 50% | 无 |
| 第二档 | 在第一档的价格上算上买卖手续费上涨10% | 卖出 25% | 锁定部分利润 |
| 第三档 | 在第二档的价格上算上买卖手续费上涨20% | 卖出 25% | 继续锁定部分利润 |
| 第四档 | 在第三档的价格上算上买卖手续费上涨20% | 卖出 25% | 继续锁定部分利润 |
| 第五档 | 80¢以上 | 卖出50%  | 无 |
| 第六档 | 90¢以上 | 全部卖出  | 无 |


## 五、止损规则（多层防护）

触发以下任一条件立即止损：

1. **价格止损**：合约价格从入场价下跌 ≥ 50%（例：25¢入场，跌至12.5¢触发）
3. **时间止损**：剩余时间 ≤ 10分钟 且 合约价格 < 20¢（明显无法翻盘）

## 六、最后10分钟特殊处理

这是原策略缺失的关键部分：

- **合约价在 0-20¢**：立即清仓离场（时间止损）
- **合约价在 20-50¢**：按止盈规则执行
- **合约价在 50-80¢**：继续按止盈规则走
- **合约价在 80¢ 以上**：取消卖出挂单，持有到期博取 $1.00 全额结算（到期获胜，从85¢到100¢是额外17%收益，胜率已经很高）

## 七、费率意识（时刻牢记）

1. Polymarket加密类市场有taker费，2026年4月30日前有50%返利
2. 限价单（maker）可以完全避免taker费——这是最大的成本优化
3. 手续费公式：`手续费 = 股数 × 0.05 × p × (1-p)`，越接近50¢越贵
4. 真实回本价不是买入价，而是：`买入价 × (1 + 买入费率 + 预计卖出费率)`

## 八、记录与复盘（必须执行）

每笔交易记录以下数据：

- 入场时间、剩余时间、入场价
- 入场时 BTC 波动率（相对均值）
- 入场时 BTC 距 strike 的百分比距离
- 离场方式（止盈档位 / 止损 / 时间止损 / 到期）
- 实际盈亏

## 九、绝对红线

1. 不追涨买入超过30¢的合约，即使"感觉要赢"
2. 不加仓到亏损的仓位（不要摊平成本）
2.5. 持仓未清前，禁止开新仓
3. 单日连续亏损3次，停止当日交易 **（dry_run 阶段暂时禁用，live 模式必须重新启用）**
4. 单日账户回撤超过5%，停止当日交易 **（dry_run 阶段暂时禁用，live 模式必须重新启用）**
5. 不在重大数据公布前5分钟入场（CPI、FOMC、非农等），价格可能瞬间剧烈波动

## 预期收益参考

单次$100仓位，在胜率35%、使用限价单的情况下，平均单次期望收益约 $3-5。关键在于通过大样本（50+次）积累正期望，而非单次盈亏。
